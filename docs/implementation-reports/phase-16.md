## Contracts and non-goals

Reuse independently validated auxiliary JSON contracts rather than changing Catalog SQL. Preserve all raw source records/unknown fields and complete revision evidence. Items retain explicit `item_<hex>` identities, each detail variant and acquisition condition; icon filenames are not IDs. Research uses explicit `progress_id` and handbook membership shared across forms, and retains recipe rewards. Medal records/statuses remain complete; only source-reviewed public statuses appear in normal browsing. Trial progress uses explicit encounter IDs and preserves region/section/form metadata. Creature links require unique exact reviewed source-title/ID mappings; unresolved or ambiguous mappings remain explicit and must not silently infer a form. Habitat pins describe areas, not exact spawns.

Use two independent typed checklist sets in the existing personal settings table, one for research and one for encounters. Missing values mean no marks; malformed existing progress must fail without overwriting it. Preserve unknown saved IDs across data changes and update UI only after successful writes. No SQL migration, personal database replacement or reuse of collection marks is allowed. Native views use DTOs through repositories; no raw parsing, direct database access, Lua/JavaScript execution, runtime Wiki request, account call or first-launch download is allowed.

New images require an explicit deduplicated manifest with source identity, hashes, dimensions and attribution using the existing verified media pipeline. Reuse exact approved files where possible; source-unavailable media must be represented explicitly, never generated or silently replaced with another pet. No large map-base/tile acquisition is authorized. Do not change dependencies, existing release artifacts, updater/installer transport, system/network/security settings, signing or publication.

Verify complete immutable source sets and counts, all required fields, identity/variant preservation, safe Lua and literal/compressed JSON parsing, error/empty/incomplete-source rejection, deterministic output, reference closure and an exact reviewed mapping report. Media checks cover declared reference closure, source hashes/paths, dimensions and active staging. Owned fixtures must prove edge cases rather than mirror the implementation. Run affected Python tests and the default offline suite, full Swift tests, packaging/localization/prose checks, generic simulator build, focused native search/detail/filter/link/progress/restart/recovery/AX tests, and inspect real captures. Confirm normative SQL/old releases/assets and personal records are preserved. Update mapped docs and evidence, review the complete allowlisted diff and `git diff --check`, then commit/push through GitHub Desktop. Report any unsupported source/mapping/media/device layer explicitly rather than manufacturing completion.
